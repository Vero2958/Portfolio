Main Projects


Voxel-wise encoding model on NSD data (in progress)

Can we predict a new subject's brain responses to images accurately when we only have a small amount of that subject's fMRI data?

In this project, I'm building a data-efficient transfer-learning framework to predict voxel-wise activations of some novel subject's brain areas by laveraging full-data encoding models previously built to predict other subjects's same brain areas. I'm currently working on building and integrating resting state-derived connectivity fingerprints into the model, as subject-specific structural constraints to personalize predictions.

Currently, the model matches (and sometimes surpasses!) the full-data baseline's performance.

Robustness of Spectral and Dynamical properties of stable cortical network models with rich dynamics. (in progress)

How do biological networks operating near instability manage to chenge their structure while still retaining stable dynamics?

In this project, I'm working with a VERY NOVEL (not published yet, but preprint available on BioRxiv), untrained network model capable of reporducing the rich repertoire of dynamics oberved experimentally in the motor cortex.

My job is essentially to break it >:). Unfortunately, I also have to fix it tho :(. I sistematically lesioned the network element by element to study how each of them contribute to stability & dynamics and how these properties deteriorate as perturbations accumulate.

Currently, I'm focusing on figuring out how the network can be rescued. To do so, I'm mapping structural vulnerabilities (such as what I baptized as an "8 structure"), testing possible compensatory mechanisms informed from both my analysis and literature, and implementing an algorithm to lesion the network mimicking the actual degeneration progression observed in ALS patients, to use a gimmik and test compensatory mechanisms in biologically plausible neurodegenerative contexts.

Lightweight Classification Models for Automated 5-stage Sleep Scoring from EEG Data

Can we find a classification model that is lightweight, based only on EEG data, interpretable and has a good trade-off between accuracy and complexity? In other words, can we build a model capable of automating sleep scoring in clinical settings?

To answer this question, I built and evaluated six distinct machine learning and deep architectures, including eXtreme Gradient Boosting (XGBoost), Random Forest, and Feedforward Neural Networks (FNN) across an engineered 96-feature EEG matrix. To map the boundary conditions of personalization versus universality, I cross-validated the models using a three-tier paradigm: Within-Subject 10-fold Cross-Validation, Pooled Subject-Dependent K-Fold, and Subject-Independent Leave-One-Subject-Out (LOSO) Cross-Validation.

Long story short, tree ensemble models won :D !

Short story long, all models performed well and each had its own advantage over the others, possibly making models that achived a lower-accuracy more suitable than higher performance models for some specific applications.

IMCSH: IMC SHELL
  • Alternavive Linux Shell in written in C. Includes 3 commands and 2 modifiers.
  • commands are: "exec" to execute a given program, "globalusage" to show a string with the details of the version of the shell that is being executed, and "quit" to quit the shell, if there's still any running program, the shell will show running processes and ask the user if they still want to quit, if so, all processes are terminated.
  • modifiers are: "&" to execute a command in the background and continue immdiately, and ">" to write the output of a command into a file.
